# Caryule

A minimal, premium, distraction-free modern web browser built with Electron, React, TypeScript, Vite, and Tailwind CSS.

## Features
- **Zen Mode**: Distraction-free browsing with customized shortcuts and wallpaper customization.
- **Railway/Qovery-Style Notch Tabs**: Signature smooth-curved tabs with zero gap attachment.
- **Adaptive Canvas**: Multiple wallpaper collections (photos, gradients, solids) with real-time blur and brightness controls.
- **Embedded Webview**: Multi-tab browsing powered by Electron webview / iframe fallback with history navigation.

## Development

```bash
# Install dependencies
npm install

# Run web preview
npm run dev

# Run Electron desktop app
npm run electron:dev
```
